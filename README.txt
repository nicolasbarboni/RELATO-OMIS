INSTALAÇÃO NO IPHONE
1. Publique o conteúdo desta pasta em hospedagem estática HTTPS.
2. Abra o endereço no Safari.
3. Compartilhar > Adicionar à Tela de Início.
4. Abra uma vez com internet para armazenar os arquivos.
5. Depois, o app funciona offline.
